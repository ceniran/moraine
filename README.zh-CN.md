# Moraine（石脉）

  <img src="assets/moraine-stone.png" width="240" alt="带有层状石脉的 Moraine 小石头标记">

[English](README.md)

Moraine 是一个面向私人文本集合的轻量本地语义索引。它不要求用户记住
精确关键词，而是按照文字表达的含义寻找相关内容；索引可以小批量增量更新、
中断后继续，并在普通 CPU 上离线运行，不依赖云端向量额度。

名字来自冰碛地貌（moraine）：许多零散石砾被时间带到一起，最终形成一条
可以辨认的地形。Moraine 也把散落的书籍、笔记、消息和资料组织成一片可以
沿着“意思”重新找到内容的语义地貌。

## 能做什么

- 用自然语言和模糊描述检索文本，即使查询与原文没有相同关键词；
- 为相关内容推荐、主题聚类和重复检测提供语义相似度；
- 从 JSON 文件或带鉴权的 HTTP 接口读取资料；
- 只重新编码新增或变化的记录，并持久化可续跑索引；
- 通过本机 HTTP API 提供健康检查、刷新与搜索；
- 在本地故障时由调用方继续使用关键词或既有云端召回。

## 典型用途

- **线上图书馆**：根据零散情节、氛围、主题或阅读偏好找书，并辅助生成多标签分类；
- **个人知识库**：忘记文件名和原句时，仍能按意思找回笔记与文档；
- **AI 记忆**：在生成回答前召回相关事件、偏好、决定和项目背景；
- **论文资料库**：从自然语言问题寻找相关摘要，并发现主题群；
- **客服与工单**：查找相似历史问题、重复事件和曾经有效的解决办法；
- **影视与游戏目录**：根据氛围、玩法或模糊剧情描述检索作品；
- **邮件与社区归档**：寻找与新消息语义相关的旧讨论。

Moraine 最适合“记得大概意思，却不知道准确标题、关键词或分类”的工作，
尤其适合重视本地处理、成本可控和简单部署的私人或中小型文本集合。

它不替代数据库。书名、作者、ISBN、日期、账号、权限和数字范围等精确信息，
仍应使用结构化字段与关键词检索；最稳妥的方案是把这些精确工具与 Moraine 的
语义候选结合起来。

## 快速开始

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
cp .env.example .env

set -a
. ./.env
set +a
.venv/bin/moraine
```

首次运行会下载 `BAAI/bge-small-zh-v1.5`。完成缓存后可设置
`HF_HUB_OFFLINE=1`，让生产检索完全离线运行。

完整数据格式、接口、安全边界与 systemd 示例请查看英文 README 和
[`docs/integration.md`](docs/integration.md)。

## 隐私边界

本仓库只包含合成示例，不包含任何私人记忆、凭证、生产路径或真实索引。
生成的 `data/index.json` 同样属于隐私数据，不应提交到 Git。

## 只读记忆治理实验

Moraine 现包含第一版可配置赋权策略，以 0～100 的“记忆强度”呈现，底层仍可
兼容 0～1 的 `importance`。规则只使用类型、现有权重、确认次数、显式优先级与
保护标记等元数据，不读取正文，也不调用文本模型。它可以比较旧分布与建议分布，
并预览保留原权重、模拟赋权、自动赋权或暂不赋权四种迁移方式。

当前模块只生成建议，始终返回 `persisted: false`。身份、关系及显式保护的记忆
即使选择自动赋权也必须人工审阅。详见 [`docs/governance.md`](docs/governance.md)。
自动建议最高为79分；80～100分的核心记忆只能由记忆主人手动赋权并锁定。
锁定、解锁和改分均要求填写操作者、时间与理由，并产生可审计记录。
